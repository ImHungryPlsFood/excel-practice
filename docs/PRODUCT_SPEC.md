## 1. 제품 개요 및 핵심 철학

### 1.1 제품 비전
**CELLCRAFT(임시명)**는 초보자가 스프레드시트를 처음 접하는 순간부터 실제 회사 업무, 고급 데이터 분석, Excel 관련 대회, 컴퓨터활용능력 자격증 대비까지 단계적으로 성장할 수 있는 **웹 기반 실습형 인터랙티브 교육 플랫폼**이다.

### 1.2 4대 핵심 기둥 (Pillars)
1. **Duolingo형 동기부여:** 명확한 학습 경로, 일일 목표, 진행도 시각화, 성취 시스템.
2. **Chess.com형 퍼즐 중심 학습:** 문제 해결 중심 학습, 단계적 힌트, 난이도 조절, 오답 복습.
3. **게임형 인터랙티브 튜토리얼:** 배경 암전 Spotlight, 자연스러운 말풍선, 단계별 상호작용 안내, 부드러운 상태 전환.
4. **실제 스프레드시트 작업 환경:** 실제 셀, 행, 열, 수식 입력줄, 서식, 차트, 데이터 처리 환경 완벽 재현.

### 1.3 최우선 차별점 및 원칙
> **"사용자가 설명을 읽는 것만으로 학습을 완료할 수 없다. 실제 스프레드시트에서 직접 작업하고, 그 작업이 올바른지 엄격하게 검증받아야 한다."**

- 기존 서비스의 로고, 캐릭터, 문구는 복제하지 않으며 독자적인 브랜드를 구축한다.
- 화려한 시각 효과보다 실제 작업 생산성과 인지적 명료함을 최우선으로 한다.

## 2. 화면별 상세 기능 명세 (Information Architecture)

### 2.1 랜딩 페이지 (Landing Page)
- **목적:** 전문적이고 신뢰감 있는 첫인상 제공 및 즉각적인 학습 진입 유도.
- **포함 요소 (필수 7종):**
  1. 독자적인 브랜드 로고 및 서비스명 (`CELLCRAFT`).
  2. 한눈에 이해되는 핵심 가치 제안 (Value Proposition).
  3. 실제 인터랙티브 스프레드시트 조작 미리보기 컴포넌트.
  4. '무료로 학습 시작하기' CTA 버튼 (체험 모드 직행 지원).
  5. 교육과정 소개 (Level 0 입문부터 Level 10 대회 문제까지).
  6. 초급부터 고급까지의 단계별 성장 로드맵 인포그래픽.
  7. 컴퓨터활용능력 1·2급 및 실무 프로젝트 대비 안내.
- **금지 규칙:** 과도한 장식 그래픽, 불필요한 자동 재생 동영상 배제.

### 2.2 대시보드 (Dashboard)
- **목적:** 로그인 후 학습자가 다음 행동을 고민 없이 즉시 실행하도록 지원.
- **표시 정보 (필수 9종):**
  1. 현재 학습 단계 (Current Level & Track).
  2. '이어서 학습하기' 원클릭 액션 카드.
  3. 오늘의 목표 (일일 경험치 및 해결할 문제 수 달성 게이지).
  4. 전체 교육과정 진행률 (% 및 완료된 단원 수).
  5. 최근 학습한 개념 카드.
  6. 복습이 필요한 개념 (망각 곡선 도래 단원 경고).
  7. 틀린 문제 다시 풀기 바로가기.
  8. 완료한 도전 과제 및 획득 뱃지.
  9. 최근 성취 기록 및 연속 학습일(Streak) 달력.

### 2.3 학습 경로 (Learning Path)
- **구조:** 단순 일직선 배치를 금지하며, 선수 관계(Prerequisites)를 반영한 **분기형 지식 그래프(DAG)** 구조 채택.
- **학습 단원 상태 (6단계 State Machine):**
  1. `LOCKED`: 선행 단원 미완료로 잠김.
  2. `AVAILABLE`: 선행 단원을 완료하여 새로 열림.
  3. `IN_PROGRESS`: 현재 학습 진행 중.
  4. `COMPLETED`: 단원 내 모든 문제 1회 이상 해결.
  5. `REVIEW_RECOMMENDED`: 일정 기간 경과로 복습 권장.
  6. `MASTERED`: 복습 및 고난도 문제까지 완벽 해결.
- **유연성 원칙:** 사용자의 진율을 불필요하게 가로막지 않도록, 진단 평가(Placement Test)를 통한 상위 단원 조기 해금 및 자유 연습 모드 상시 개방.

### 2.4 실제 학습 화면 (Interactive Learning Workspace)
- **레이아웃:** 데스크톱 최적화 3분할 워크스페이스.
  - **상단 헤더 (Height 48px):** 현재 단원명, 진행 단계 인디케이터(예: 3/5 Step), 나가기 버튼.
  - **좌측 안내 패널 (Width 280px):** 학습 개념 설명, 현재 단계에서 해야 할 행동, 단축키 팁.
  - **중앙 스프레드시트 작업 공간 (Flex Grow):** 수식 입력줄(Formula Bar), 열/행 헤더, 자체 가상화 인터랙티브 그리드, 시트 탭.
  - **우측 피드백 패널 (Width 320px):** 달성해야 할 구체적 조건 체크리스트, 단계별 힌트 아코디언, 채점 결과 피드백.
  - **하단 유틸리티 바 (Height 40px):** 실행 취소(Undo), 다시 실행(Redo), 처음부터 다시 풀기, 단계 건너뛰기(선택적 허용 시).

### 2.5 자유 연습실 (Sandbox Room)
- 정규 학습 모드와 명확히 분리된 자유 실습 공간.
- **제공 기능 (9종):**
  1. 빈 스프레드시트 즉시 생성.
  2. 사전 제공 실무 샘플 데이터셋 불러오기.
  3. 셀 편집 및 다중 범위 서식 지정.
  4. 수식 및 함수 자유 입력 및 연산.
  5. 여러 워크시트 생성/삭제/이름 변경.
  6. 서식 지정 및 기본 차트 렌더링.
  7. 무제한 Undo / Redo 지원.
  8. 사용자 개인 브라우저/계정에 실습 파일 저장.
  9. 로컬 XLSX 파일 가져오기 및 내보내기 (보안 파이프라인 준수).

## 3. 학습 및 채점 시스템 명세

### 3.1 튜토리얼 엔진 (Tutorial Engine)
- **선언적 스키마 기반:** 코드가 아닌 선언적 데이터(`TutorialStep`)로 단계를 정의한다.
- **상호작용 검증:** 설명창의 '다음' 버튼 클릭만으로 단계를 통과시키는 행위를 엄격히 금지한다. 반드시 지정된 셀에 수식이 입력되고 정상 계산된 이벤트가 발생해야 다음 단계로 전이한다.
- **Spotlight 오버레이:**
  - 강조 대상을 제외한 주변 화면을 어둡게 처리.
  - 오버레이가 사용자의 마우스/키보드 입력을 가로막지 않음.
  - 셀 가상화 상태를 고려하여 뷰포트 내 절대 좌표를 동적으로 재계산.

### 3.2 채점 시스템 (Grading System)
- **문자열 단순 비교 금지:** 수식 결과값만을 정답 문자열과 비교하는 방식을 금지한다.
- **구분 판정:**
  1. 수식 정답 및 정확한 결과
  2. 대체 수식(다른 유효한 함수 조합)으로 도달한 정답
  3. 숫자를 직접 하드코딩하여 우연히 맞힌 경우 (오답 판정)
  4. 수식은 맞으나 참조 범위가 누락/과다한 경우 (구체적 피드백 제공)
  5. 상대/절대 참조 오류 (데이터 교란 시 틀리는 경우 판정)
- **오답 복구 원칙:** 오답 발생 시 사용자가 작성한 데이터를 무차별 초기화하지 않고, 실행 취소(Undo)를 통해 오류 직전 상태로 복구할 수 있게 한다.
- **4단계 힌트 시스템:** 사용자가 직접 클릭할 때만 공개 (개념 힌트 -> 범위 힌트 -> 수식 구조 힌트 -> 완전한 정답 해설).

## 4. 실제 업무 데이터셋 및 확장성

- **가상 실무 데이터셋 10종 지원:** 판매 내역, 재고 관리, 고객 목록, 지출 내역, 직원 근태, 주문 데이터, 부서별 실적, 날짜별 활동, 노이즈/오류 데이터, 다중 시트 통합 자료.
- 현실적인 비정형 데이터(공백, 중복, 대소문자 불일치, 날짜 형식 오류)를 포함하여 실제 현업 데이터 정제 능력을 기르도록 설계.
- 개인정보(PII) 및 실제 기업 기밀 일체 배제 (100% 가상 생성 데이터).

## 5. 게임화 및 동기부여 명세

- **경험치 (XP):** 개념 학습(+10), 일반 문제 해결(+20), 힌트 없는 완전 자율 해결(+30), 복습 완료(+15), 프로젝트 완성(+100). (쉬운 문제 반복 풀이를 통한 어뷰징 방지 상한 적용).
- **연속 학습 기록 (Streak):** 하루 결석 시 모든 누적 기록이 초기화되는 가혹한 정책을 지양하고, 'Streak Freeze(연속 기록 보호권)' 및 주간 복구 미션 제공.
- **업적 (Achievements):** 실제 행동 기반 7대 핵심 업적 수여 (첫 수식, 절대참조 마스터, 첫 차트, 10연속 정답, 오답 완전 복습, 첫 실무 프로젝트, 무힌트 챌린지).
- **간격 반복 복습 (Spaced Repetition):** 에빙하우스 망각 곡선에 기초하여 오답 및 힌트 다빈도 문제를 1일, 3일, 7일 주기로 복습 큐에 자동 배치.
